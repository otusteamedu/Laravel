Основные таблицы:
1) Пользователи (берется из основного приложения)
2) Селектор: пользователь - маршрут обучения
   (ссылка на маршрут, ссылка на пользователя,
   ссылка на последнюю пройденную точку маршрута, для которой контрольный тест сдан -- id из селектора точек маршрута)
3) Маршруты обучения (название)
4) Селектор: маршрут обучения - точка маршрута (фактически реальные точки маршрута имеющие свою дату сдачи экзамена)
   (ссылка на маршрут, ссылка на точку маршрута, дата контрольного теста по точке маршрута)
5) Точки маршрута (название) -- фактически справочник
6) Учебные материалы (ссылка на тип материала, путь к файлу, ссылка на точку маршрута)
7) Тип учебного материала (название)
8) Экзаменационные вопросы (название вопроса ,текст вопроса, ссылка на точку маршрута)
9) Ответы к вопросам (название ответа, тескт ответа, ссылка на вопрос)

Создание миграций
./vendor/bin/sail artisan make:migration [create\alter\]_table_name_[table] --path=app/Modules/ISS/database/migrations
Создание фабрик
./vendor/bin/sail artisan make:factory ../../app/Modules/ISS/database/factories/EducationRouteFactory
Создание сидера
./vendor/bin/sail make:seeder /path/to/seeder/ModelNameSeeder.php

Связи
Тип учебного материала (1) -- (*) Учебный материал
Ответ экзамена         (*) -- (1) Вопрос Экзамена
Точка маршрута         (1) -- (*) Вопрос экзамена
Точка маршрута         (1) -- (*) Учебный материал
Маршрут                (*) -- (*) Точка маршрута (селектор точек)
Маршрут                (*) -- (*) Пользователь (селектор пользователей)
Селектор пользователей (1) -- (1) Селектор точек маршрута (связь нужна для привязки последней пройденной точки маршрута для пользователя)
